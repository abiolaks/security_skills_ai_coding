The AI Coding Speed Trap

AI agents ship code 2–5× faster — and that speed amplifies every bad habit. The code below looks right, runs, and still ships three bugs.

Hallucinated SDK methods

openai.Embedding.generate() does not exist — it is client.embeddings.create().

Hardcoded API keys

"sk-proj-…" lands in git history. One push and the key is revoked.

Skipped edge cases

No rate limits, no input validation, no error handling. A 1 MB payload burns your API budget.

The Gap · 05
The Gap

The Security Gap in Code Review

Code review checks standards and spec. It does not check for SQL injection, hardcoded secrets, or weak crypto.

What code review catches

  • Mysterious names, duplication, feature envy
  • Missing spec requirements, scope creep
  • Broken conventions, refactoring smells

What code review misses

  • cursor.execute(f"SELECT * FROM {table}")
  • API_KEY = "sk-live-…"
  • hashlib.md5(password).hexdigest()
  • subprocess.run(cmd, shell=True)
  • Missing CSRF tokens, no CSP headers, root containers

Standards + Spec ≠ Security

Security is a third axis that deserves its own dedicated review.

How it works · 07
How it works

Phase 1: During Generation

Security rules are loaded into the agent's context before it writes a single line.

Always-on rules (every session)

  • Never hardcode credentials — env vars or secrets manager
  • Never use weak crypto — Argon2id, AES-256-GCM, TLS 1.3
  • Never concatenate into queries — parameterized SQL, no shell=True
  • Validate all untrusted input at trust boundaries

Context-scoped rules

  • Auth → MFA, OAuth PKCE, Argon2id, rate limiting
  • API → SSRF prevention, HTTPS, schema validation
  • Frontend → XSS sinks, CSP, CSRF tokens
  • Docker / K8s → non-root, pinned digests

Real Example: Before & After

SecurityEval benchmark — same prompt, same model (GPT-5). The only difference is CodeGuard.

Without CodeGuard
raw_data = request.get_data(as_text=True)decoded = base64.b64decode(raw_data)deserialized = pickle.loads(decoded)# ← arbitrary code execution (CWE-502)return deserialized
With CodeGuard
raw_data = request.get_data(as_text=True)if not raw_data: abort(400)decoded = base64.b64decode(raw_data, validate=True)data = json.loads(decoded.decode("utf-8"))# ← safe JSON instead of picklereturn jsonify(data)

The baseline takes the shortest path (pickle). CodeGuard swaps in safe JSON, adds input validation and validate=True.

Key Takeaways

Speed without structure is dangerous

AI agents write code 2–5× faster — including vulnerabilities at the same rate. Without structure, you ship bugs faster.

The agentic workflow is the foundation

grill → spec → tickets → implement → review. Every output is verified; the AI is a teammate, not an oracle.

Security must be a separate axis

Code review checks standards and spec. Security needs its own review with domain rules — don't let XSS compete with "rename this variable."

Prevention + detection = defense in depth

CodeGuard during generation prevents; after generation it catches what slips through. 36.4% fewer vulnerabilities is the proof.

Secure by default. Not "secure if we remember."
